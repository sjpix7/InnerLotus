eft.point.kc.where = 手の外側の肉厚な部分、手首と小指の間。

eft.point.th.where = 頭のてっぺんの中央。
eft.point.eb.name = 眉頭
eft.point.eb.where = 眉毛が始まるところ、鼻のすぐ上の少し横。
eft.point.se.name = 目の横
eft.point.se.where = 目尻の外側の骨の上。
eft.point.ue.name = 目の下
eft.point.ue.where = 目の下の骨の上、瞳の真下。
eft.point.un.name = 鼻の下
eft.point.un.where = 鼻と上唇の間の小さな部分。
eft.point.ch.name = あご
eft.point.ch.where = 下唇とあご先の間のくぼみの中央。
eft.point.cb.name = 鎖骨
eft.point.cb.where = 鎖骨の内側の端のすぐ下、中心から2〜3センチのところ。
eft.point.ua.name = わきの下
eft.point.ua.where = 体の側面、わきの下から約10センチ下。
eft.point.gp.name = ガミュートポイント
eft.point.gp.where = 手の甲、薬指と小指の付け根の関節の間のくぼみ。

eft.tech.basic.name = 基本のレシピ
eft.tech.basic.desc = 定番の方法：空手チョップのポイントでセットアップを行い、気持ちを認めるラウンドのあと、前向きなラウンドを行います。日常使いに最適です。
eft.tech.full.name = 9ガミュート付きフルレシピ
eft.tech.full.desc = 2つのラウンドの間に、Gary Craig の9ガミュート手順を加えます。目の動き、ハミング、数を数えることで左右の脳を働かせます。
eft.tech.gentle.name = やさしいタッチと呼吸
eft.tech.gentle.desc = たたく代わりに、各ポイントに指先を置いて、ゆっくり深くひと呼吸します。夜や人前、とても敏感になっているときに最適です。
eft.tech.positive.name = ポジティブラウンド
eft.tech.positive.desc = 前向きな言葉だけを使って各ポイントをたたき、気分がよくなったあとの落ち着きと自信を定着させます。

eft.gamut:
- 目を閉じます。
- 目を開けます。
- 頭を動かさずに、右下をしっかり見ます。
- 次に左下をしっかり見ます。
- 目をぐるりと一周回します。
- 反対方向に目を一周回します。
- 楽しい曲を数秒ハミングします。
- 1から5まですばやく数えます。
- もう一度その曲をハミングします。
