learn.affirmations.title = 肯定语如何进入潜意识
learn.affirmations.body <<
肯定语是用现在时表达的简短正面语句，你反复重复，直到它们开始让你感觉真实。它们依靠三件事发挥作用：重复、情绪和注意力。

潜意识主导着你一天中的大部分时间：习惯、自动反应，以及对你所做的一切不断评论的内在声音。它更多地通过重复和感受来学习，而不是通过逻辑。当同一个想法被经常重复，尤其是带着情绪时，大脑会强化支持它的神经通路。这就是神经可塑性：你练习什么，就会成为什么。

研究支持这一原理。在自我肯定实验中，反思自己核心价值观的人更能应对压力，也更愿意接受改变。一项脑成像研究（Cascio 等，2016）发现，自我肯定会激活与奖赏和自我认知相关的脑区。肯定语还会训练你的注意力：大脑会筛选你注意到的事物，于是你开始看见与你所重复的内容相符的机会。

有一点需要注意。完全感觉不真实的语句可能适得其反，尤其是在自尊心较低时（Wood 等，2009）。请选择你能相信的肯定语，或者让它更温和："我正在学习……"、"我正在敞开……"、"每一天都更……"。

如何练习：
• 为你想疗愈的领域选择三到五条肯定语。
• 在早晨和睡前心灵最容易接受的时候，慢慢地大声说出或默念。
• 去感受它们。想象它们已经成真的那一刻。
• 结合缓慢的呼吸、脉轮练习或写日记。
• 保持持续。每天一点，胜过偶尔很多。

本应用的每张卡片都以脉轮的核心语句开头：我存在、我感受、我行动、我爱、我表达、我看见、我知晓。从海底轮开始一路向上到顶轮，或选择今天你想平衡的能量中心。

learn.eft.title = 什么是 EFT 敲击？
learn.eft.body <<
情绪释放技巧（EFT），常被称为"敲击疗法"，是一边用指尖轻轻敲击穴位，一边说出自己感受的方法。它由 Gary Craig 在 1990 年代推广，源自 Roger Callahan 博士的思维场疗法。

为什么要做：当你专注于一种令人不安的感受时，敲击会向身体发出平静的信号。研究者认为，这能降低杏仁核——大脑的威胁探测器——的压力反应，让记忆或情绪在你与它同在时逐渐失去力量。

研究怎么说：EFT 已在一百多项临床试验中被研究。荟萃分析显示，焦虑（Clond，2016）、抑郁（Nelms 与 Castel，2016）和创伤后应激障碍症状（Sebastian 与 Nelms，2017）都有显著下降。在一项随机研究中，仅仅一小时的 EFT 后，压力激素皮质醇下降了约 24%，远高于谈话治疗组和休息组（Church 等，2012）。

人们的体验：
• 心更平静，焦虑更少
• 缓解压力、渴望和紧张
• 更容易入睡
• 放下旧伤、恐惧和限制性信念
• 在考试、面试和演讲前更有自信

基本流程：
1. 说出问题，并用 0 到 10 给它的强度打分。
2. 准备语：敲击手掌外侧的"手刀点"，同时把准备语说三遍："即使我感到……，我依然深深地、完全地接纳自己。"
3. 敲击顺序：在每个点上敲五到七次，同时说一句简短的提醒语：头顶、眉头、眼尾、眼下、鼻下、下巴、锁骨和腋下。
4. 深呼吸，再次给强度打分。重复直到感觉好转。

用两根手指轻轻敲击。EFT 是一种自助练习，不能替代医疗或心理健康服务。处理创伤时，最好在受过训练的专业人士陪伴下进行。

learn.hooponopono.title = 什么是荷欧波诺波诺？
learn.hooponopono.body <<
荷欧波诺波诺（Ho'oponopono）是夏威夷的和解与宽恕练习。这个词的意思是"纠正"或"使之正确"。传统上，家人会和一位长者坐在一起，讨论冲突、承担责任、彼此原谅并放下，从而恢复和谐。

1970 年代，夏威夷疗愈师 Morrnah Simeona 把它发展成任何人都能独自完成的练习。她的学生 Ihaleakala Hew Len 博士教导说，我们可以为生命中出现的一切负起全部责任，方法是清理自己内在的记忆，而不是试图改变他人。他与 Joe Vitale 合著的《零极限》让四句简单的话闻名全球：

对不起——我承认我内在的某些东西参与造成了这一切。
请原谅我——我请求自己、他人和神圣的原谅。
谢谢你——感谢这份疗愈和这堂课。
我爱你——爱是转化与疗愈的能量。

它能帮助你：
• 放下怨恨、内疚和旧伤
• 缓和伴侣和家庭中的冲突
• 平静心灵，安抚反复出现的念头
• 为金钱、健康和人生挑战带来慈悲
• 感到与自己和神圣相连

如何练习：想着一个人、一种情境或一种感受。慢慢呼吸。真诚地重复这四句话——大声说、默念或写下来——持续几分钟，或想多久就多久。不需要任何其他人参与，清理发生在你的内在。

荷欧波诺波诺是一种灵性练习。它的传统形式与现代形式有所不同，也不能替代专业帮助。

learn.journal.title = 为什么写日记能疗愈
learn.journal.body <<
写日记就是把你的想法和感受写下来这一简单的练习。它把头脑中的嘈杂变成可以看见、理解和放下的文字。

为什么有帮助：1980 年代，心理学家 James Pennebaker 请人们连续三到四天，每天花十五到二十分钟写下自己最深的想法和感受。在接下来的几个月里，他们看医生的次数更少，情绪也更好。此后，数百项研究把表达性写作与更低的压力、更好的睡眠、更强的免疫力和更清晰的思考联系在一起。感恩日记——写下你感恩的事——已被证明能提升乐观和幸福感（Emmons 与 McCullough，2003）。

写作能帮助你：
• 处理情绪，而不是压抑它们
• 发现情绪、触发点和习惯中的规律
• 在睡前让奔腾的思绪平静下来
• 设定意图并追踪自己的成长
• 培养自我觉察和自我关怀

在这里如何写日记：
• 自由地写，不要修改。错别字不重要。
• 不知道从何写起时，可以使用提示。
• 试试"感恩"模式：今天的三件好事。
• 记录心情，随着时间看见自己的情绪旅程。
• 日记只保存在这部手机上，并按日、周、月整理。你可以随时导出、导入或删除。

每天五分钟就够了。诚实地、温柔地对待自己——这是属于你的安全空间。

learn.sound.title = 声音如何疗愈
learn.sound.body <<
声音疗愈利用音调、节奏和自然之声，帮助身体放松、心灵平静。当我们聆听稳定而舒缓的声音时，呼吸会变慢，心跳会平稳，注意力也会从担忧中移开。

研究显示：
• 雨声、水声、鸟鸣等自然声音，比交通噪音更能帮助身体从压力中恢复（Alvarsson 等，2010）。
• 双耳节拍——左右耳听到略有不同的音调，感知为柔和的脉动——在 2019 年的一项荟萃分析中对焦虑、注意力和疼痛显示出小到中等的效果（Garcia-Argibay 等）。请佩戴耳机聆听。
• 40 赫兹的伽马刺激正在被研究用于记忆和大脑健康。
• 在一项观察性研究中，颂钵冥想减少了紧张、愤怒和疲劳（Goldsby 等，2017）。
• 528 Hz 等索尔费吉奥频率和 432 Hz 调音来自灵性和音乐传统。相关研究仍然很少，所以请把它们当作放松练习，而不是治疗。

如何使用本板块：
1. 选择一个疗愈频率，或把自然声音和乐器混合成你自己的声景。
2. 调整每一层的音量，并保存你喜欢的混音。
3. 设置睡眠定时器，让声音在背景中持续播放。
4. 慢慢呼吸，只是聆听。

请把音量保持在轻柔舒适的水平。如果你有癫痫、心脏起搏器或听力问题，使用节奏性或双耳声音前请先咨询医生。本应用中的所有声音都在你的设备上实时合成，无需下载任何内容。

learn.breath.title = 呼吸的科学
learn.breath.body <<
呼吸练习是有意识地运用呼吸来改变自身状态。呼吸是神经系统中唯一可以直接控制的部分：长而缓慢的呼气会启动让人平静的副交感神经系统，而快速吸气则带来能量。

在 2023 年的一项斯坦福研究（Balban 等）中，每天五分钟的"循环叹息"——用鼻子深吸一口气，再短短补吸一口，然后长长地呼气——比正念冥想更能改善情绪、放慢呼吸。每分钟约六次的慢呼吸能提高心率变异性，这是韧性的标志。交替鼻孔呼吸和"蜂鸣式"呼吸等瑜伽调息法，几百年来一直帮助人们平静心灵。

小提示：
• 尽可能用鼻子呼吸。
• 保持轻柔，不要用力。
• 如果感到头晕，就停下来正常呼吸。
• 每天练习。即使三分钟也有帮助。

learn.chakra.title = 七个脉轮
learn.chakra.body <<
"脉轮"（Chakra）是梵文，意思是"轮子"。瑜伽和密宗传统描述了沿脊柱从底部到头顶的七个能量中心。每个脉轮都与一种颜色、一种元素、一个种子音（Bija）以及生活中的特定领域相关。

1. 海底轮（Muladhara）：我存在。安全与扎根。
2. 脐轮（Svadhisthana）：我感受。情绪、创造力与愉悦。
3. 太阳神经丛轮（Manipura）：我行动。意志、自信与行动。
4. 心轮（Anahata）：我爱。爱、慈悲与宽恕。
5. 喉轮（Vishuddha）：我表达。真相与表达。
6. 眉心轮（Ajna）：我看见。直觉与洞察。
7. 顶轮（Sahasrara）：我知晓。连结与灵性。

通过呼吸、声音、颜色和肯定语来练习脉轮，是把觉知带到生活不同领域的一种方式。从海底轮开始向上，或专注于今天最需要的那个中心。脉轮系统是一张灵性与冥想的地图，而不是解剖图。
